# Barça Platform

Интерактивная сине-гранатовая платформа для болельщиков FC Barcelona: прогнозы матчей, тактическая доска, Fantasy, трансферный центр, рейтинги, геймификация и закрытый клуб Socio 1899.

## Локальный запуск

1. Скопируйте `.env.example` в `.env.local` и добавьте публичные параметры Supabase.
2. Установите зависимости.
3. Запустите development-сервер командой `npm run dev`.

Реальные ключи и `.env.local` не должны попадать в Git.
