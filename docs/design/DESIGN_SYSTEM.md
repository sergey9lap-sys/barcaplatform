## Shadows and Effects

### Shadows
Use restrained shadows:
- subtle card elevation
- more visible on modals / hero blocks

### Glow
Can use soft blue or garnet glow in small amounts:
- active card border
- selected state
- CTA emphasis

Do not overdo neon.

### Blur
Glassmorphism is allowed only lightly:
- subtle backdrop blur for sticky headers / overlays
- not for whole app
